# APIFit

## Outcome

Help PMs and early-stage builders find APIs and MCP servers for a product idea,
understand which documented capabilities could help, and prepare a build brief.

## Why now

The project demonstrates product discovery, a simpler search-first interaction,
evidence-aware AI, measured iteration and cost-conscious engineering. It is a
tool the owner would use while deciding how to build a product.

## Current state

The independent source repository is public and MIT-licensed, with a
reviewer-oriented README, product scope, decision history, architecture,
deployment instructions and 226 passing offline tests. Public hosting support
includes isolated visitor sessions, bounded requests, runtime-secret handling
and an unchanged cumulative AI spending ledger. CI checks source and builds the
container. The app has not been deployed.

Search evaluations and retained failures are documented rather than presented
as universal accuracy claims. Postman integration has been removed from scope.
The owner handles the demo and chose public access with paid AI available.

## Next action

Choose hosting and a domain; verify the real HTTPS deployment and securely
configure the runtime credential and original ledger before enabling public AI.
Confirm the remaining shared allowance is adequate without resetting the cap.
